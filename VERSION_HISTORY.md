# Version history

## V1.0 — Legacy Project baseline

- Establishes the current workspace snapshot as the baseline for studying the existing RFID firmware.
- Adds a recruiter-facing overview of the repository purpose and learning roadmap.
- Limits the Git scope to reviewable firmware sources, documentation, and files needed to understand or build the project.
- Excludes generated build outputs, local data, editor state, and Wokwi simulation configuration.
- Does not change firmware behavior.

Future commits should use a short `Vx.y — topic` title and update this file with a concise description of changes from the previous version.
